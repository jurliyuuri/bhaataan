boríṣán báni

現代バート語の古めの表記。borúḷ は「〜に由来する」という意味であり、つまり boríṣán báni は直訳すれば「来歴の文字」、要するに「語源綴り」ということ。

gháyo

大文字で転写する。歴史的経緯の情報を含み、それだけでは現代音を必ずしも読み取れないため、あくまでそこに「美しさ」を流し込んで完成形とするための「鋳型」とみなされている。

母音字

矢印の先には、無標のときの行き先を書いておいた。

I → i U → u Í → í Ú → ú
É → e Ó → o
È → ai Ò → au
(無表記) → a Á → á

Ъ: 母音のないことを示す母音字。

子音字

赤背景は外来語

矢印の先には、無標のときの行き先を書いておいた。

P → p T → t Z → z K → k ʔ → Ø
F → p C → c X → x H → h
B → bh D → dh G → gh
V → bh S → s R → r
M → m N → n Ɲ → ṇ Ŋ → ṇ
W → h L → l ~ ḷ J → j

長子音記号 Q

子音字の前に置いて、直後の子音を伸ばす。日本語学などで用いられる促音モーラの表記にかこつけて Q を転写に用いる。

借用語マーカー「:」

借用語の直前に置く。ヒッタイト楔形文字には Glossenkeil という「ルウィ語などからの借用語の直前に置く記号」𒑱 があり、これの伝統的な transliteration がコロンであるので、同等の機能を持つ記号を我々もコロンで転記することとする。

eghibhát

石に彫られていたときの伝統的な書記体系。

大まかには gháyo と同じだが、「F と V の区別」「Ɲ と N と Ŋ の区別」をせず、長子音記号 Q を表記しない。借用語マーカーはあった。

hámí

「鋳型」gháyo に、「美しさ」を流し込んで完成形とすることで、現代音を表すのに必要な情報が揃う。

転写では、一貫して下につく記号として表せるように、IPA や extIPA などの記号を援用して以下のように転写することとする。

lowered ◌̞ (U+031E)
advanced ◌̟ (U+031F)
retracted ◌̠ (U+0320)
strong articulation ◌͈ (U+0348)
weak articulation ◌͉ (U+0349)
短い鼻音への縮約 ◌Ъ◌
長い鼻音への縮約 ◌Ъ◌
短い噪音への縮約 ◌Ъ◌
長い流音への縮約 ◌Ъ◌

下線および波線が引けない環境下で hámí を転写するためには、

  • 短鼻音括弧 [◌Ъ◌] (U+005B および U+005D)
  • 長鼻音括弧 〚◌Ъ◌〛(U+301A および U+301B)
  • 短噪音括弧 ⧘◌Ъ◌⧙ (U+29D8 および U+29D9)
  • 長流音括弧 ⧚◌Ъ◌⧛ (U+29DA および U+29DB)
を用いる。

具体例

boríṣán báni は非常に歴史に引きずられているため、これを使うと同根語や関連語の間の関係が見出しやすい。

後置格/無格 ṣaghi「上」と主格 ṣá「上が」
C̠GI → ṣaghi
  1. C には retracted の記号がついているので ṣ
  2. 母音字が付加されていないので a
  3. G は gh
  4. I は i
ゆえに ṣaghi
C̠G͉Ъ → ṣá
  1. C には retracted の記号がついているので ṣ
  2. 母音字が付加されていないので a
  3. G は weak articulation がついているので ◌́（これは、音節末であり直前が短母音であることが原因）
  4. Ъ はゼロ
ゆえに ṣá
このように、boríṣán báni で書くと、主格 ṣá と後置格/無格 ṣaghi が同じ語であることが分かりやすい。

ゆえに bhoghi (ただし現代正書法上は bhogi と綴る)

ゆえに bhog

  • 「顎を下げる」という操作を表す lowered はだいぶ vocalic な記号であり、おもに母音・半母音の類いに付着し、より開いた母音・半母音を生み出す。
  • 「舌を前に進める」という操作を表す advanced は consonantal な記号である。ただ、ṣiṇṇa の例からも見て取れるように、両隣の子音が舌の操作を行っている際に、母音がそこに巻き込まれることもある。
  • 「舌を後ろに下げる」という操作を表す retracted も、これまた consonantal な記号である。ただし、 i/í は反り舌音に必ず巻き込まれるので、そのことを明記する用途にも用いる。
  • strong articulation は完璧に consonantal な記号であり、母音字には使わない。 無声音については「p/k を強めたものが ph/kh」、有声音については「bh/gh を強めたものが b/g」という直感があり、それを反映した振る舞いとなっている。
    • 特に b は分布がかなり限られている。
      • 「補助動詞 -(a)boh-」を含む語頭 M 群は当然 M の strong articulation と見なすことになる。
      • 男性終止詞はなぜか -(a)bá ではなく -(a)bhá であるので、三人称男性 -(a)bát [名詞化], -(a)báta [過去分詞], -(a)báṣlo [未来分詞] は M 群であるとはできず、B の strong articulation と見なすべきであると分かる。
      • 三人称未来分詞 -(a)hobá [中性受動], -(a)zebá [女性能動] も同様に B の strong articulation と見なすべきであろう。
    一方で D は dh よりも d のほうが無標であるようには思えるが、B/G との一貫性のために bo_bá という書記体系の上では「無標が dh」となっている。
  • weak articulation は、語源的な関係を有する（と、少なくとも信じられている）様々な散発的な縮約や音の変化などをカバーするための記号である。
